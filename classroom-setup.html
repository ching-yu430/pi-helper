啟用共用課堂功能

由有 Supabase 管理權限的老師完成一次即可。

升級共用求助、教材開放與上課模式

  1. 先確認目前使用的 Supabase 專案，並保留既有資料庫備份。
  2. 下載下方 SQL，在該專案的 SQL Editor 開啟新查詢，貼上並執行一次。
  3. 執行成功後，重新整理學生與助教頁面，再登入工作台管理驗證。

升級只新增課程設定、求助資料與相關函式，不重設既有課堂、帳密、期限或學生回報。需要既有的組數升級已完成。

下載升級 SQL

學生自行記錄的進度與設備勾選可先使用。共用求助清單、教材開放與老師同步上課模式需完成此升級後才會啟用。不要把登入密碼或資料庫憑證貼到對話中。

啟用每人獨立登入

  1. 先完成上方共用課堂功能升級。
  2. 執行下方帳號升級 SQL，再重新整理工作台管理。
  3. 用原本的密碼登入管理員，在「課堂設定 → 登入帳號設定 → 管理其他登入帳號」新增每人的名稱與密碼。
下載個人帳號升級 SQL

每人只需輸入自己的密碼即可登入。管理員可修改或停用帳號；其他人可修改自己的名稱與密碼。求助接手會自動記錄登入名稱。原本密碼與課堂資料保留。
