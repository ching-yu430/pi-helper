工作台管理課程首頁

啟用共用課堂功能

由有 Supabase 管理權限的老師完成。

使用同一份安裝／升級檔

  1. 確認目前使用的 Supabase 專案，先備份資料庫。
  2. 下載完整 SQL，在該專案的 SQL Editor 貼上並執行。
  3. 成功後重新整理網站，登入工作台確認課堂與帳號，再測試求助與上課模式。
下載完整安裝／升級 SQL

安裝檔會依編號執行尚未完成的升級，記錄版本與校驗碼；重跑會跳過已完成版本，錯誤時回滾整批。保留課堂、帳號、期限及回報，不會自動清除看板。

既有課堂不要執行建課檔。新專案完成安裝後，再依 資料庫設定說明 建立課堂並設定公開連線資料。不要將管理密碼或資料庫憑證貼到對話中。

個人登入與共用求助

用原管理員密碼登入，在「課堂設定 → 登入帳號設定」新增各人的名稱與密碼。求助接手會記錄實際登入者；學生可確認結果或再次求助。

看板清除

完整安裝檔已包含看板清除修正。升級後到「課堂設定 → 清除看板與求助紀錄」操作；清除後學生仍可重新求助。

老師帶課與暫停提示

完整安裝檔已包含暫停提示。重新登入老師上課模式，按「開始帶課」後測試「先停在這裡」，上方應顯示「暫停中」；按「繼續上課」解除。暫停期間學生仍可閱讀與求助。
