先刷機，再用 .local 登入，最後開啟遠端桌面。已做完的部分可以跳過；不確定就問助教。

  1. 01
    準備與刷機

    把系統裝進 SD 卡

    第一次使用時，照圖解把系統寫入 SD 卡。設備可在上方展開檢查。

    做到這裡：寫入與驗證都成功，再把 SD 卡放進 Pi 開機。

    開始本組刷機圖解 →
  2. 02
    SSH 連線

    從 Windows 登入本組 Pi

    Windows 電腦與 Pi 連上同組熱點，再到 PowerShell 貼上登入指令。

    做到這裡：用 本組主機名稱 登入，確認組別與帳號正確。

    開始本組 SSH 連線 →
  3. 03
    遠端桌面

    在 Windows 看見 Pi 的桌面

    先登入 SSH，再照步驟安裝遠端桌面、設定 X11 並重新開機。

    做到這裡：遠端桌面的 Session 選 Xorg，成功進入本組 Pi 桌面。

    開始本組遠端桌面教學 →
  4. 04
    每次下課都要做

    先關機，再拔電

    先儲存作業，再執行關機。只關閉遠端桌面視窗不會讓 Pi 關機。

    做到這裡：執行關機後至少再等 30 秒，確認關機完成才拔電；不確定就請助教確認。

    開始本組正確關機 →
