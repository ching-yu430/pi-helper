# 2026-11-01 課程與後台檢視

## 教學呈現

每個學生操作畫面都要能回答：在哪台設備、哪個視窗、按什麼、貼在哪裡、做完看見什麼。主畫面顯示完成當下操作必需的內容；補充原理與少見錯誤保留在摺疊區。

本次補齊：

- 樹莓派桌面如何開啟終端機，複製指令後如何切回並貼上。
- Thonny 從哪個選單開、Ctrl+N 新增、程式貼在上方而非下方 >>>、Ctrl+S 填完整路徑儲存。
- 寫程式與執行程式分開標示操作位置；執行寫檔程式後如何用樹莓派檔案管理員開啟 message.txt。
- AI 提問使用 Windows 瀏覽器，取得程式後回樹莓派 Thonny；保留學生自行提問及六項功能要求。
- 樹莓派照片使用完整路徑與 Ctrl+L 開啟；下載到 Windows 後如何用檔案總管開啟 JPG。
- 每行指令下方直接顯示預期結果；不以按下一步代替實際執行證據。
- 重開機、關機與舊課程的操作位置補充；修正使用說明過時的「第 04 課」入口名稱。

維持既有配色、卡片、字級、複製按鈕與響應式版面。320px 手機可上下捲動閱讀，沒有要求縮小文字把所有必要說明塞進單一畫面。

## 後台修正

舊資料庫未提供課程檢查 RPC 時，若還沒有舊檢查資料，不能將所有組別誤判為回報失聯。此情況現在提示需更新資料庫，並保留瀏覽器回報分類。真正的網路錯誤仍保留上次紀錄，標示狀態待確認。

修正歷史測試所用的入口、已摺疊的舊教材／進度、六種統計及求助優先排序；使用組別識別選取組卡，不以第幾張卡假設組別。舊資料庫模擬對不存在的 RPC 回傳與 PostgREST 一致的 PGRST202。

## 檢查範圍

- 所有 17 支瀏覽器流程：首頁與失敗重試、刷機／SSH／遠端桌面／關機、Python 與照片、複製、求助、後台帳號／設定／組卡／篩選／工具更新、教材同步與投影、隔離示範工作台。
- 全部 10 支 SQL 測試：在獨立 PGlite 測試資料庫執行，不寫入正式課堂。
- Python 工具與還原測試，及 HTML／JavaScript 靜態檢查、SQL 打包、資源版本、工具不可變套件校驗。
- 實際瀏覽器檢查 320、390、768、1280px 的課程與後台；投影另涵蓋橫向手機、全螢幕與 1920px。

檢視不等同真實 Windows、Pi 相機或學生理解度驗收。需要現場實測的項目仍依 [實機清單](CLASSROOM_CHECKLIST.md) 驗收；程式測試不能保證所有學生都能一次完成。

本機結果：17／17 支瀏覽器流程、10／10 支 SQL 流程、643 項靜態檢查通過。Python 共 85 項，81 項通過，4 項需 root／桌面顯示環境，在 GitHub 的既有隔離 CI 執行。
