# 課前實機驗收

狀態：尚未執行。自動瀏覽器與資料庫測試不代表已在實體手機或 Pi 驗收。

準備一支真正的手機、一台 Windows 筆電及一台 Raspberry Pi 5；使用測試用 SD 卡與測試課堂，避免覆寫學生作業。測試者、日期、手機／瀏覽器、Windows 與 Imager 版本、Pi OS 版本、結果及問題另記錄。

- [ ] 手機打開課程首頁，選組後所有課程都帶入正確組別；320～390px 寬度不需左右滑動。
- [ ] 中斷網路後開啟首頁，10 秒內有讀取失敗提示、重試與找助教文字；恢復網路重試可選組。
- [ ] 刷機圖解逐張比對真實 Imager，核對 Pi 5、64-bit 桌面版、本組 SD 卡、hostname、user、熱點與 SSH；不可照抄圖片中的範例值。
- [ ] 寫入與驗證完成，Pi 插卡供電；筆電與 Pi 連同組熱點，用本組 .local 登入。
- [ ] 依序測試指紋確認、密碼不顯示、核對 hostname／whoami；只有 .local 排查仍失敗才由助教協助查 IP。
- [ ] 完成遠端桌面安裝，X11 三個選單都對照真機；重開機後選 Xorg 登入。
- [ ] 學生送出求助，助教收到、接手、請學生再試，學生確認成功或重新求助；雙方狀態一致。
- [ ] 老師在實際教室投影設備進入全螢幕，逐頁檢查文字、圖片、上下頁、暫停文字及恢復；長文字不能讓圖片連帶縮小。
- [ ] 放大圖片後點圖標記，再捲動、放大、還原，確認圓圈位置正確；測試停止、重新啟用與清除。
- [ ] 儲存成果後正確關機，至少再等 30 秒並由助教確認後才拔電；關閉遠端視窗不等於關機。
- [ ] 設備回報：升級 SQL、在真實 Pi 安裝一次、重新開機後自動回報；核對 SSH／xrdp、X11 設定與 USB 相機插拔。切斷網路後顯示暫無回報，恢復後可更新；重新配對後舊設備憑證失效。
- [ ] 找第一次接觸 Pi 的測試者，只看操作頁完成「在哪個視窗操作 → 一行一行執行 → 對照預期結果」，並能展開「畫面不一樣？」及送出求助。

有未通過的項目先記錄重現步驟與畫面，再修正後重測；由現場老師／助教確認適合上課。
