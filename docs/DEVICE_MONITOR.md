# 樹莓派設備回報

這項功能另外顯示 Pi 回傳的設備檢查，與學生自行回報的學習進度分開。不會自動替學生標記完成、操控桌面或執行網頁下達的指令。

## 啟用順序

1. 在 Supabase SQL Editor 執行最新的 [完整安裝／升級檔](../supabase/install.sql)，包含新增的 `013_device_monitor.sql`。既有課堂不要重建。
2. 工作台登入後，開啟「課堂設定 → 樹莓派設備回報」，選擇組別，按「產生安裝設定碼」。每組只有一個有效設備憑證，重新產生會立即讓舊憑證失效。
3. 先用 `.local` 登入這組 Pi，在 **Pi 的 SSH 視窗**依序執行頁面上的下載與安裝指令。使用 Raspberry Pi OS 內建的 Python 3，不用 pip 安裝套件。
4. 安裝程式出現提示時，貼上安裝設定碼並按 Enter。輸入內容不顯示。主機名稱必須與組別相符，例如第 03 組為 `pi5-03`；不符時會停止安裝。
5. 安裝成功後回看板，確認「已收到 Pi 設備回報」。重新開機後也要驗證一次；重刷 SD 卡後需重新安裝。

安裝設定碼含有此組專用設備憑證，只交給該組安裝使用。它不能登入工作台或讀取其他組別。不要放入公開教材、Git 或截圖。網頁不會把它保存到瀏覽器儲存空間，關閉看板會清除畫面上的設定碼。

## 能檢查什麼

| 資料 | 解讀方式 |
| --- | --- |
| 主機名稱 | 與選定組別是否一致，不含 Pi 序號 |
| SSH、xrdp | Pi 本機服務狀態；不保證學生筆電連得上 |
| xrdp、xorgxrdp 套件 | 套件是否已安裝 |
| X11／Wayland | LightDM 的本機桌面設定，無法辨認時顯示無法確認；改設定後仍需依教材重新開機 |
| Python | 系統 Python 3 版本；不代表未來課程套件已完整安裝 |
| USB 相機 | 系統偵測到的 USB 影像裝置數；不代表影像擷取已測試成功 |
| 可用空間、開機秒數 | 根目錄可用空間與 uptime；只供設備排查 |

每 30 秒送出一次，連線失敗會逐漸延長重試，最長 5 分鐘。資料庫用伺服器時間記錄最後收到回報；看板超過 90 秒未收到會標示「Pi 暫無回報」。過期資料會明確標示為上次收到的資料，不代表當前設備狀態。

不收集 Wi-Fi 名稱與密碼、IP、學生檔案、指令歷史、螢幕內容、相機畫面或完整日誌。資料庫僅保存允許的欄位與每組最後一筆資料，不累積軌跡。設備回報仍屬設備程式提供的檢查，不是硬體驗證或防作弊機制。

## 看不到回報時

- **設備回報尚未啟用**：先完成 SQL 升級、產生設定碼並安裝；學生仍可照原本步驟上課。
- **等候 Pi 首次回報**：確認安裝已完成、Pi 可連外上網，課堂已開放且未到期。
- **Pi 暫無回報**：檢查供電、手機熱點、行動網路和回報服務。不要因此拔電或直接重刷。
- **設備狀態讀取失敗**：是網站這次沒有取得狀態，不能判定 Pi 故障；按立即更新或重新檢查。
- **主機名稱不同**：先確認設定碼是否交錯組別，核對設備名稱；更名後需依教材重新開機。

以下指令一次執行一行，在該組 Pi 的 SSH 視窗操作：

查看服務：

```sh
systemctl status pi-helper-device.service --no-pager
```

查看回報程式最近訊息（只在本機看，不自動上傳）：

```sh
sudo journalctl -u pi-helper-device.service -n 30 --no-pager
```

網路已恢復但仍無回報時重新啟動：

```sh
sudo systemctl restart pi-helper-device.service
```

## 停用、移除與權限

工作台按「停用此組設備回報」會撤銷此組憑證，SSH 與遠端桌面不受影響。恢復時產生新設定碼重新安裝即可。清除學生看板紀錄不會停用設備回報；兩者用途不同。

Pi 端停止並取消自動啟動：

```sh
sudo systemctl disable --now pi-helper-device.service
```

如不再使用，停止服務後刪除 `/etc/pi-helper-device.json`、`/etc/systemd/system/pi-helper-device.service` 及 `/usr/local/lib/pi-helper-device/`，再執行 `sudo systemctl daemon-reload`。專用系統帳號 `pi-helper-reporter` 不允許互動登入，可由管理員視需要移除。

安裝時需要 sudo；執行時使用無互動登入權限的專用帳號，設定檔為 root 所有、專用群組可讀（0640）。設備憑證以 SHA-256 雜湊保存在資料庫，只有產生時回傳明文；僅能更新配對組別的設備狀態。資料表啟用 RLS 並撤銷匿名直接存取，所有操作經過限定權限的 RPC。

## 上課前驗收

自動測試使用隔離資料庫及模擬 Pi 狀態；請另用真實 Pi 5、Windows 筆電與手機熱點驗證：第一次安裝、重新開機、暫時斷網與恢復、xrdp 啟停、切換 X11 後重新開機，以及 USB 相機插拔。先確認本組設備收到回報，再發給學生使用。
