# 樹莓派 5 課堂網站：精簡版

學生依網站逐步完成刷機、SSH、套件安裝、X11 設定、重新開機、遠端桌面與關機。助教使用組別看板與排查工具。

## 本版內容

- 看板只顯示真實課堂；移除虛構資料、額外組別捷徑及快速套用按鈕。
- 移除所有 PDF、下載入口及獨立教學總覽，必要內容整合到原本的刷機與逐步排查流程。
- 助教只在排查工具的連線設定選一次組別；切組會清掉舊 IP，避免沿用其他設備目標。
- 保留登入、九組狀態、更新／登出、課堂開關、截止日期、密碼設定與紀錄清除。
- 保留六步操作導覽，清楚標示網頁、Windows PowerShell 與 Pi SSH 的操作位置。
- 保留手機版單欄、觸控按鈕與安全區留白。

## 更新 GitHub Pages

1. 將本套件的 HTML、JS、responsive.css、assets/imager/ 與 .nojekyll 覆蓋到原儲存庫。
2. 在儲存庫另外刪除舊版的 course-guide.js、assets/handouts/ 與 TEACHING_REVIEW.md。只上傳新版不會自動刪掉 GitHub 上的舊檔。
3. 等待 Pages 部署成功，再重新整理。所有本機資源使用相對路徑。

本版未變更 config.js 或 SQL。現有專案已完成清除功能的資料庫升級，這次不用再執行 SQL，也不必更改助教密碼。

## 使用

學生先選組別。尚未刷機就開刷機圖解；已刷機就開始 SSH；已登入 SSH 可直接進入安裝與設定遠端桌面。依實際執行結果選下一步，不要把範例輸出當成已驗證的結果。

助教登入組別看板查看回報；要排查時切換排查工具，設定本組後選學生遇到的情況。SSH 核對完成後，可接續網站內的更新、安裝、啟用、X11 與重新開機教學。

清除本機排查只重設本頁；清除看板紀錄由助教登入後選單組或全班。學生若持續操作，新的回報會再次出現。

執行 node tests/run-tests.cjs，無需安裝依賴。369 項檢查通過，包含兩端流程節點、安裝順序、指令、同步佇列、登入／登出、清除範圍與取消，以及刪除功能後的引用檢查。

此為本機交付套件，尚未上傳 GitHub；本次未做瀏覽器畫面、實體手機或 Pi 驗證，也未再次修改正式資料庫。
