先關機，再拔電

課堂同步無法使用時，仍可照這裡完成關機。

先儲存，再執行關機

  1. 儲存本組樹莓派上的程式與作業。
  2. 切到已登入本組 Pi 的 SSH 視窗，或開啟 Pi 桌面的終端機。不要把關機指令貼到尚未登入 Pi 的 Windows PowerShell。
  3. 在 Pi 執行：
    sudo shutdown -h now
    若詢問密碼，輸入目前 Pi 密碼再按 Enter。
  4. 連線中斷是正常的，先不要拔電。至少再等 30 秒；仍有活動就繼續等，不確定請助教確認。
  5. 確認關機完成後才拔電，收好 SD 卡、讀卡機與電源。

關閉 Windows 遠端桌面視窗不等於關機。此頁只提供教學，沒有偵測或回報 Pi 是否已關機。
