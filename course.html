今天從哪裡開始？

第一次接觸樹莓派也沒關係。照順序做，一次完成一件事。

目前可開始

先讓樹莓派可以操作

先刷機，再用 .local 登入，最後開啟遠端桌面。已做完的部分可以跳過；不確定就問助教。

這裡列的是課程順序，不會自動判定你已經做完。看板狀態仍以學生自行回報為準。

  1. 01
    準備與刷機

    把系統裝進 SD 卡

    準備 Windows 電腦、Pi 5、電源、SD 卡、讀卡機與手機熱點。先在操作頁選組別，再按「① 尚未刷機」。

    做到這裡：寫入與驗證都成功，再把 SD 卡放進 Pi 開機。

    前往選組與刷機圖解 →
  2. 02
    SSH 連線

    從 Windows 登入本組 Pi

    Windows 與 Pi 連同組手機熱點。在操作頁選自己的組別，按「② 已完成刷機」，再把指令貼到 PowerShell。

    做到這裡：用本組 pi5-XX.local 登入，確認組別與帳號正確。

    前往選組與 SSH 連線 →
  3. 03
    遠端桌面

    在 Windows 看見 Pi 的桌面

    先完成 SSH 登入，再按操作頁的「已登入 SSH，開始安裝與設定遠端桌面」。照步驟安裝、選 X11、重新開機，再連線。

    做到這裡：遠端桌面的 Session 選 Xorg，成功進入本組 Pi 桌面。

    前往遠端桌面教學入口 →
  4. 04
    每次下課都要做

    先關機，再拔電

    先儲存作業，再從操作頁的正確關機入口開始。關閉遠端桌面視窗不等於關機。

    做到這裡：執行關機後至少再等 30 秒，確認關機完成才拔電；不確定就請助教確認。

    前往正確關機步驟 →
